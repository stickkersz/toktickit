**LLM/agent used:** Claude Code (Sonnet 5), Anthropic's CLI coding agent, run interactively in this repo's working directory across the whole Lab 2 sprint.

**How it was used, in one line:** as an implementation and code-review partner working from the approved spec docs and a real reciprocal-review workflow with a classmate, never allowed to call something "done" without a passing test suite and a manually re-checked diff.

## My Reflection

The agent was fastest at the mechanical work, but almost every real bug this sprint came from making it stop and actually use the app instead of trusting a green test run. The stale-response race in My Tickets and the read-only fields that looked identical to editable ones both passed every mocked test and were only caught by opening a browser and looking. It also introduced a regression once: its own fix for a loading-state bug in PR #20 silently swallowed every later error, and my partner caught that in review, not me.

The peer review loop turned out to be the most useful part. Twice I flagged something on my partner's PR and then found the same bug in my own code: the attachment-limit race and the nav that highlighted nothing on Ticket Detail. Reviewing someone else's code taught me what to look for in mine faster than just writing more of my own.

The main thing I had to keep correcting was tone and scope: its first review comment on my partner's PR read like a formal audit report, and it would happily mark documentation "done" while test rows still said Pending for tests that had passed for days. Passing tests never meant the submission was complete, and that judgement stayed mine at every checkpoint.
